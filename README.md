# Business-Sales-Profit-Analytics-Dashboard
Power BI dashboard built using Excel data to analyze global sales and profit trends across categories, years, and regions. Includes KPIs, charts, and interactive slicers for business insights.
# Business Sales & Profit Analytics Dashboard

## 🎯 Goal
To analyze sales and profit trends across categories, years, and regions using Excel data in Power BI.

## 📌 Objectives
- Prepare and clean data in Excel.
- Import data into Power BI and model relationships.
- Build interactive dashboard with KPIs, charts, and slicers.
- Generate insights for business decision-making.

## 🛠 Tools Used
- Microsoft Excel
- Power BI
